# 工业设计典型测试用例

`npm run test:suite` 在同一个工作台里，用原生工具依次执行有代表性的工业设计用例。每个用例的预期在执行前就写在脚本里。“通过”表示原生结果与预期一致，不表示设计被采用，有些用例的预期本来就是拒绝。

默认运行 30 个用例（Y1、K1 需要 `npm run setup:physics`，D2 需要 `npm run setup:cam`），CI 跑的就是这一组。2026-10-05 新增的 D1、D2 与相关的 C1、C4、M1 单独运行（`PAI_SUITE_ONLY=C1,C4,D1,D2,M1`），5/5 通过。另有两个用例需要显式开启：
- A3：设置 `PAI_SUITE_LIVE_AI=1`，调用真实模型，消耗 1 次真实尝试。
- X1：设置 `PAI_AGENTCORE_SANDBOX_ARN`，使用 AgentCore 云端沙箱。

最近一次实际运行开启了这两项，共 27 个用例（2026-10-03）。完整运行 26/27 通过：X1 因本机实例角色没有 `InvokeAgentRuntime` 权限返回 403，是环境问题，不是产品代码问题。之后用受限的运维角色单独重跑 X1（`PAI_SUITE_ONLY=X1`），通过。两次结果都保留在 [industrial-suite.json](evidence/industrial-suite.json) 里。可以用 `PAI_SUITE_ONLY=P1,P2` 只运行指定的用例。

运行环境：Blender 5.2.2 LTS；CadQuery 2.8.0 / OCCT 7.9.3（哈希锁定安装）；Robot Reel `6124cee3cba5`；Factory Twin `b3ee5c7d2c55`；EvalArc 独立对照。

## CAD 用例怎么测量

零件是 NEMA 17 步进电机的 L 形安装支架，6061 铝，名义尺寸。配方是受控脚本 `native/cad_bracket.py`，只接受固定的变体名和数值需求，不接受上传的 Python、STEP 或几何文件。所有检查都在 OCCT B-Rep 上实际测量：

- 实体有效性：BRepCheck，要求是单一闭合实体。
- NEMA 17 接口：从圆柱面读出止口孔直径（要求 ≥ Ø22.2）、4 个 M3 孔（Ø3.4，按 ISO 273 中等配合）和 31.0 mm 方形孔距。
- 电机装配干涉：零件与 NEMA 17 机身、Ø22 止口、Ø5 轴做布尔交集，要求交集体积为 0。
- 最小壁厚：取相对平面之间、以及孔与孔之间的最小距离，并要求两者之间确实是材料。
- 孔边距：紧固孔中心到所在面外轮廓的距离，要求 ≥ 1.5×d；d 为 B-Rep 实测的间隙孔直径。本配方的 M5 间隙孔为 Ø5.5 mm，故门槛为 8.25 mm；M5 螺纹的名义直径为 5 mm。这是本演示的经验规则，不能替代载荷、材料、公差或适用规范的校核。
- 质量与外形包络：B-Rep 体积乘以名义密度；外形取 OCCT 原生几何的轴对齐包围盒，显式关闭已有网格与形体容差扩张，避免 GLB/STL 网格影响名义尺寸验收。这不代表制造公差已经验证。

每次评审输出可编辑的 STEP，以及 STL、GLB、装配 GLB、SVG 工程视图和原生检查结果，全部记录 SHA-256。另有独立脚本 `native/cad_reopen.py` 重新导入 STEP，核对体积和孔径。

## 边界

这些用例覆盖四类证据：历史仿真记录、合成静态几何、名义参数化零件和演示用工厂仿真。没有做 FEA、公差叠加、加工过程仿真、实物测试或现场测量。Blender 和 CAD 的合成配方不代表测得的工厂；Factory Twin 的参数没有按真实工厂校准。
